#BuildHybridAI 2026 · Firebase AI Logic + App Check

LearnFlow Companion

A hands-free, AI-powered technical reader for Google Skills, O'Reilly, and YouTube. Runs on-device with Chrome Gemini Nano when possible and falls back to Gemini in the cloud via Firebase AI Logic + App Check.

View Open-Source Repo on GitHub ↗

⚡ On-Device (PREFER_ON_DEVICE)

Code Whisperer explanations, 2-minute section briefings, Anki flashcards, and 3-question Study Quizzes run locally via Gemini Nano on supported devices, at zero cost and low latency.

☁️ Cloud Fallback (ONLY_IN_CLOUD)

Multimodal Figure Vision (explaining complex architecture diagrams) and fallback inference route securely through Firebase AI Logic protected by App Check.

🔌 Pluggable AI Router

Switch cleanly in Settings between Firebase AI Logic (Hybrid) and Direct Gemini (API Key / Chrome Nano) without changing your workflow.

Quick Setup

git clone https://github.com/akmalkhaniub/learnflow-companion.git

In chrome://extensions/, turn on Developer mode and click Load unpacked on the cloned folder (no build step needed). Open the Side Panel (Alt+Shift+L) → Settings. The Firebase config is pre-filled, so paste an App Check debug token, save, and click Test AI connection. On devices without Gemini Nano, every task runs in the cloud automatically.
